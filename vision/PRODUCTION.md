# The Awakening / production record

Original 84-second company vision artwork, authored in `scripts/vision-renderer.js`. Deterministic Canvas 2D projects animated 3D surfaces, packets, beacons and architectural planes into 1280×720 frames at 24fps. Local Playwright Chromium captures JPEG frames to a pipe; bundled FFmpeg from Python imageio-ffmpeg encodes H.264/yuv420p with faststart, plus compact 640×360 VP9 WebM alternatives. No stock footage, generative imagery, remote fonts, music, voice recording or third-party visual references are used. The existing approved logo is preserved. New pages use a 108-pixel WebP derivative of that same artwork so the original 1.4 MB PNG does not delay this exhibit.

Source boundaries: the public `/financial/` pages establish paper-money founding beta status and unavailability of live customer investing. `/ai/`, `/systems/` and `/industries/` explicitly establish prospective research status. The six-agent sequence is a proposed independent engineering review model, not an assertion about operational infrastructure. Geometry is illustrative, not telemetry. Tests and permissions are engineering principles, not a security certification. The presentation contains public corporate direction and these same boundaries only.

Reproduction: `npm ci`, install Python `imageio-ffmpeg` with `python3 -m pip install --target node_modules/.vision-python imageio-ffmpeg`, then run `node scripts/render-vision.cjs`. Use `bash scripts/vision-browser-env.sh <command>` for this host’s existing Chromium/WebKit library environment. Run `bash scripts/setup-vision-media.sh` once to extract additional GStreamer decoder plugins locally under ignored `node_modules/.vision-media` for WebKit media tests; this does not install system packages. The setup is specific to Ubuntu 26.04. `python3 scripts/build-vision.py` regenerates page text, scene JSON, captions and cue sheet. `node scripts/verify-vision.cjs` records browser validation. No backend or customer service is needed.

The optional ambient loop reverses its time parameter on a cosine trajectory for a seamless eight-second cycle. It is silent, has native controls, and never autoplays. The main page assigns video sources only after an explicit Play action (WebKit can sniff sources despite `preload="none"`), a small responsive poster on mobile, native media controls, a caption track and a complete HTML transcript. A no-JavaScript visit retains playback, transcript, navigation and poster artwork. The presentation retains a transcript link without JavaScript. All notes are public.

The silent edit is intentional. See `cue-sheet.md` for an exact ten-act VO and real-guitar instrumental brief. A commissioned recording and written music rights are required before an audio edition. Suggested refinements: a professionally recorded voice performance, mastered guitar score, a higher-resolution offline master, and a creative review of scene-specific pacing. None is represented as delivered here.
